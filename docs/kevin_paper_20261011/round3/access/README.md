NACC was the first application submitted. Its live form supports a truthful independent-researcher request; it does not guarantee acceptance. SCAN is part of the NACC ecosystem, so overlapping NACC/SCAN participants cannot be treated as independent sources. The provider's current imaging page distinguishes actual images from numerical summaries; request both the eligible T1 volumes and linkage/QC metadata. [NACC imaging availability](https://www.naccdata.org/about-nacc-data/imaging-data/)

For BrainLat, the MRI-specific form is required even though the public wiki lists CC0. Account existence, license text and granted access are separate facts. The multimodal cohort size must not be used as the T1 sample size. The provider has announced changes to MRI participant codes; use a single verified release and its matching diagnosis/site table. [Provider notice](https://www.synapse.org/Synapse:syn51549340/discussion/threadId=10819)

MIRIAD has 69 participants and repeated scans; it offers useful external and repeatability research, but repeated scans are not independent patients. Its UCL terms prohibit redistribution without prior agreement. Registration availability must be rechecked before any acquisition.

An access approval is only the first study gate. Before fitting, verify patient and source grouping, clinical reference definitions, scan/assessment timing, image QC, provider-approved use and a reserved external cohort. Existing observed Harvard, Besga, OpenNeuro and legacy benchmarks cannot become untouched tests again. A research paper would not establish clinical readiness or permission to use the model for patient care.
